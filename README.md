# Dashboard-statistical
Understand dataset structure and quality:

View column data types, missing values, and unique counts.
Identify columns needing transformation or cleaning.
Perform statistical exploration:
Analyze key summary stats (mean, min, max, std) for numeric fields.
Create DAX measures to replicate .describe() outputs.
Categorical insights:
Generate value counts (.value_counts() equivalent) for Sex, Pclass, Survived, Embarked.
Visual insights and trend analysis:
Use bar charts, pie charts, boxplots, scatterplots, and matrix visuals.
Create pairwise and heatmap-style relationships using visual cross-highlighting.
Identify survival trends by sex, class, age, fare, and port of embarkation.
